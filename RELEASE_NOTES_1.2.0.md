# Potts Modern Theme 1.2.0

Version 1.2.0 introduces a new personalisation system while retaining the responsive heritage design of Potts Modern.
- Added persistent homepage block collapse preferences, stronger keyboard focus styling, clearer active navigation and an unobtrusive back-to-top control.

## Highlights
- Refined existing homepage blocks with semantic styling, restrained event accents, subtle motion and improved mobile behaviour.

- Seven colour presets
- Three typography weights
- Three content density settings
- Standard, Wide and Full Width layouts
- Live preview on the theme settings page
- Improved menus, cards, tables, buttons and forms
- Corrected search, report and advanced-search field widths for webtrees 2.2.6
- Continued compatibility with Potts Hero Slideshow

## Requirements

- webtrees 2.2.x
- PHP version supported by the installed webtrees release

## Upgrade

Replace the existing `potts_modern_theme` module folder with the folder from the release ZIP, then clear the webtrees cache and refresh the browser. Existing preferences are retained.


## Homepage experience

- New Storytelling, Classic and Compact homepage modes.
- Optional welcome heading and introductory message.
- Optional homepage quick search.
- Automatic full-width placement of the Potts Hero Slideshow when installed.
- Quick-style buttons and a Potts Modern Experience setting for coordinated homepage cards and presentation.

# Potts Modern Theme 1.3.0

Potts Modern Theme 1.3.0 is the stable release of the 1.3 development cycle for webtrees 2.2.x.

## Main improvements

- Introduces the first stable foundation for semantic life-event presentation on individual pages.
- Adds Light, Standard and Bold typography-weight presets.
- Improves dropdown sizing for long and translated menu labels.
- Strengthens masthead and heading contrast.
- Keeps the logged-in homepage main and sidebar columns stable in translated languages.
- Keeps Favourite blocks contained within their selected homepage column.
- Fixes the **Add a favourite** AJAX dialog appearing below its dark backdrop.
- Replaces legacy webtrees placeholders in Potts Narrative Ancestor Book output with Potts Modern male, female or neutral silhouettes.
- Expands translation coverage and incorporates updated Dutch translations.
- Documents 12 other Potts modules and related projects in the README.

## Upgrade

1. Back up or rename the existing `modules_v4/potts_modern_theme` folder.
2. Extract the release ZIP so the installed folder is `modules_v4/potts_modern_theme/`.
3. Clear the webtrees cache and hard-refresh the browser.
4. Check the homepage, individual pages, Favourite individuals and any installed Potts book or biography modules.

## Compatibility

- webtrees 2.2.x
- the same PHP version required by the installed webtrees release
- current Chrome, Edge, Firefox and Safari releases

The theme does not modify webtrees core files.

# Potts Modern Theme 1.4.0-alpha.7

This test build addresses GitHub issue #19.

## Fixed

- Standard webtrees silhouettes used by third-party chart modules are no longer mirrored after Potts Modern replaces them.
- The replacement image deliberately drops the webtrees `wt-icon-flip-rtl` utility class because that class belongs to the original icon glyph rather than the replacement artwork.

All fixes from alpha.6 and earlier are retained.
